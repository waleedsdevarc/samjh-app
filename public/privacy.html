Privacy Policy

Last updated: August 5, 2026

Samjh is a free biogas savings calculator. This page explains, in plain language, what data the app collects, why, and who can see it. There is nothing hidden here beyond what's written below — you can also read the actual source code at the GitHub repository to verify any of this yourself.

What Samjh does not do

  • No cookies
  • No analytics or tracking scripts (no Google Analytics, no Facebook Pixel, no anything like that)
  • No accounts, no sign-up, no passwords for regular users
  • No names, emails, phone numbers, or location data are ever asked for or collected

What Samjh does collect

When you use the calculator, the numbers you enter (how many cows, buffalo, and goats, and your chosen LPG price) and the results calculated from them are sent to our server and saved in a database, along with the date and time. That's it — just the numbers. Nothing that identifies who you are is attached to this record.

This data is used only to show aggregate usage statistics to the site owner (e.g. "how many people have used the calculator, and what's the average savings shown"). It is not sold, shared, or used for advertising.

Text-to-speech ("Listen to Everything")

If you tap the listen button, the calculated savings summary (a sentence like "you save X rupees a month") is sent from our server to Google's public Translate text-to-speech service to generate the audio. Google receives this text and the request comes from our server, not directly from your device. No personal information is included in that text — only the calculated numbers.

Fonts

This site loads the Noto Nastaliq Urdu font directly from Google Fonts (fonts.googleapis.com) so Urdu text displays correctly. Loading a font this way means your browser makes a direct request to Google's servers, which can see the IP address that request came from, the same way it would for any website that uses Google Fonts this way.

Where the app runs

Samjh is hosted using the following third-party services, each of which processes traffic/data as part of running the site:

  • Netlify — hosts the website itself
  • Render — hosts the backend server
  • Turso — hosts the database where calculation numbers are stored

Abuse prevention

The server temporarily notes the IP address of incoming requests to prevent spam/abuse (for example, limiting how many admin login attempts can be made in 15 minutes). This is kept in memory only, is never written to the database, and is cleared whenever the server restarts.

Admin dashboard

There is a password-protected admin page used only by the site owner to view aggregate usage numbers and export or clear the data described above. It requires a separate password not available to regular visitors.

Questions

If you have a question about any of this, open an issue or reach out via the site owner's GitHub profile.
